# Runtime install for Prefect Cloud managed execution (`--with-requirements requirements.txt`).

# Fully pinned on purpose. The container installs from this file, not from uv.lock, so any
# unbounded range let it resolve newer releases than the pipeline was verified against — that
# drift silently broke MLflow twice (skops serialization default, and runs:/ registration).
# Exporting the lock keeps the container byte-identical to the local environment.
#
# `-e .` stays editable: churn/flows/mlflow.py resolves paths via Path(__file__).parents[3],
# which a site-packages install would break. Notebook-only packages live in the `eda` group,
# which is excluded here (as is `dev`), so they never reach the 2 GB container.
#
# Regenerate after changing dependencies:
#    uv lock && uv export --no-hashes --no-dev --format requirements-txt -o requirements.txt
